fragen.json erzeugt

  1. Die Datei liegt jetzt im Download-Ordner und heißt fragen.json.
  2. Im GitHub-Repository in den Ordner wechseln, in dem index.html liegt.
  3. Dort Add file → Upload files wählen, die Datei hineinziehen und mit Commit changes bestätigen. Eine bestehende Datei wird dabei ersetzt.
  4. Nach ein bis zwei Minuten hat GitHub Pages die neue Fassung. Auf den Tablets die Seite einmal neu laden.

Solange die lokalen Änderungen auf diesem Gerät bleiben, gelten sie zusätzlich zur Serverfassung – das ändert nichts am Ergebnis, kann aber später verwirren.
